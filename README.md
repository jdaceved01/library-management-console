#Library Management Console App

Console-based library management system developed in C#.

##Features
- Interactive console menu
- Naviation between menus and submenus
- Input validation
- Simulated operations for books, users, loans and reports

##Technologies
- .Net 10
- C#
- Git Flow
-VSCode

##Project Structure
Feature branches are used for each module:
- project bootstrap
- menu navigation
- books module
- users module
- loans module
- search and reports
- persistence
-exit flow
